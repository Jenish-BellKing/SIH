# AI Models Directory
Owned by: Team 1 (AI/ML)

Store pre-trained weights here (e.g. `yolov8n.pt`, `yolov8s.pt`).

> [!NOTE]
> Heavy model weight binaries (`*.pt`, `*.onnx`, `*.engine`, `*.bin`, `*.safetensors`) are ignored by `.gitignore` to keep the Git repository lightweight.
> Pre-trained YOLO weights will be auto-downloaded by Ultralytics on first run.
